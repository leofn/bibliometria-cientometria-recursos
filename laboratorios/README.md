Os laboratórios formam uma sequência. Use um corpus pequeno primeiro; escalar dados antes de compreender as decisões aumenta erros e dificulta auditoria.

1. [OpenAlex e Crossref: coleta documentada](01-openalex-crossref.md)
2. [Limpeza, desambiguação e redes](02-limpeza-e-redes.md)
3. [Análise com bibliometrix/Biblioshiny](03-bibliometrix.md)
4. [Mapas com VOSviewer](04-vosviewer.md)
5. [Auditoria de cobertura e vieses](05-auditoria-de-cobertura.md)

Cada laboratório produz um artefato reutilizado no seguinte. Prefira dados abertos. Bases comerciais são comparadores opcionais, não pré-requisitos.
