# Como usar este curso

## Antes de começar

Você não precisa dominar programação. Os laboratórios oferecem rotas com interface gráfica e com código. Conhecimentos de estatística descritiva ajudam a partir do módulo 03; análise de redes é introduzida progressivamente.

## Método de estudo

Para cada módulo:

1. leia os objetivos e anote o que já sabe;
2. percorra as leituras essenciais na ordem indicada;
3. registre conceitos, decisões metodológicas e dúvidas;
4. realize a atividade ou laboratório;
5. responda às perguntas de revisão sem consultar o texto;
6. avance apenas quando cumprir o checklist **Avance quando**.

## Três tipos de leitura

- **Principal:** leitura estruturante, preferencialmente integral ou nos capítulos indicados.
- **Complementar:** aprofundamento, contraponto ou consulta metodológica.
- **Biblioteca:** referência para dúvidas específicas; não integra a carga obrigatória.

## Diário de aprendizagem

Crie um arquivo por módulo com quatro seções: `conceitos`, `decisões`, `evidências` e `limites`. No projeto final, esse diário se transforma no registro metodológico.

## Ética e direitos

O repositório fornece metadados, anotações próprias e links. Não distribua textos protegidos sem autorização. Respeite termos de uso, limites de API, dados pessoais e licenças das fontes.
